📊 Social Media Performance & Engagement Dashboard

🚀 Project Overview
This project focuses on transforming raw social media tracking data into an automated, interactive dashboard. It provides clear visual insights into audience growth, reach, and user engagement across platforms like Facebook, TikTok, and Instagram.

🚨 Key Business Problems Solved
• Manual Data Entry Bottlenecks: Replaced hours of manual cross-platform tracking with automated visual analytics.
• Low Engagement Tracking: In-depth metrics analyzing why certain posts or videos miss target audience reach.
• Platform Performance Silos: Combined data from Facebook and TikTok into a single view to compare performance trends.

🛠️ Tools & Technologies Used
• Data Visualization: Microsoft Power BI / Advanced Excel
• Data Automation & Cleansing: Power Query & DAX
